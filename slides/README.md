# Course slides

Start the interactive deck from the repository root:

```bash
python slides/serve_slides.py --port 8765
```

Open `http://127.0.0.1:8765/slides.html`.

The deck contains the measured training charts, the real pretraining generation animation, architecture walkthroughs, the reinforcement-learning experiment, and the miniature vision experiment. The feedback editor saves local notes to `slide-feedback.json`; that personal editing file is intentionally not committed.

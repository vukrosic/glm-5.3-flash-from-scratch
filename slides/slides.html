The attention rhythm in code

One condition selects the attention algorithm for every layer.

self.layers = nn.ModuleList([
    HyperConnection(
        config,
        HybridBlock(
            config,
            sparse=((index + 1) % 4 == 0),
        ),
    )
    for index in range(config.layers)
])

self.attention = (
    SparseAttention(config) if sparse
    else LinearAttention(config)
)

One expression creates the rhythm

index + 1

1. Count naturally: convert zero-based indices into layers 1 through 12.

(index + 1) % 4 == 0

2. Mark every fourth layer: layers 4, 8, and 12 become sparse.

SparseAttention if sparse else LinearAttention

3. Choose the mechanism: all other layers use linear attention.

One hybrid block

def forward(self, x):
    x = x + self.attention(self.attention_norm(x))

    ffn, usage = self.moe(self.ffn_norm(x))

    return x + ffn, usage
